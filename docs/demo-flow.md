# LinkFluence Demo Flow

1. Open the home page and explain the creator discovery problem.
2. Select **Discover Creators** and filter by niche or platform.
3. Open a creator profile and discuss profile metrics.
4. Select **Create Brief** and enter a brand, campaign title, niche, platform, budget, follower target, and description.
5. Submit the form to calculate and display a ranked creator shortlist.
6. Open **Dashboard** to see saved campaign briefs and match counts.
7. Explain that the current matcher is a transparent heuristic scoring algorithm and the data is sample data.

## Suggested demo test
- Niche: Food
- Platform: Instagram
- Budget: ₹10,000
- Target followers: 30,000
- Campaign title: New menu launch

## Important
This is a prototype. It does not yet include login, real social-platform APIs, payments, direct messaging, or a trained machine-learning model.
